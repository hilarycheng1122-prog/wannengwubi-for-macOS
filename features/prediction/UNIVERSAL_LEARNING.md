# v0.5.0 通用联想与个人学习

## 目标

根据已经上屏的简体中文推荐下一个词，不区分前词由五笔还是拼音产生。通用数据库解决首次安装的冷启动，个人数据库只负责把用户常用搭配提前或补入候选。

## 数据流

```text
上屏前词
  ├─ predict.db → 通用高频候选
  └─ personal_predict.userdb → 个人候选
                ↓
          合并、简体化、去重
                ↓
            最多 7 项
```

个人候选出现至少 2 次后参与推荐，并以使用次数和最近使用时间计算顺序。通用候选保持数据库原始顺序；重复候选保留个人候选。

## 安装

```bash
make prediction-alpha
make install-universal-learning
```

当前 Alpha 使用 `rime/librime-predict` 的 `data-1.0` 数据库作为通用底库，下载地址和 SHA-256 固定在 `upstream/versions.lock`。数据库不进入普通 Git 历史。

## 开关与隐私

- `Control + Shift + P`：关闭或开启全部下一词联想。
- 方案选单中的“个人学习”：暂停或开启个人记录。
- `make reset-personal-learning`：先备份，再清空个人数据库。
- 所有查询和学习完全离线；公开版本不包含任何用户的个人数据库。

## Alpha 验收

1. 新数据库为空时，上屏“今天”等常见词能直接出现通用候选。
2. 连续输入“万能”“五笔”至少 2 次后，上屏“万能”时“个人”候选排在通用候选之前。
3. 通用与个人候选相同时只显示一次。
4. 通用库未命中而个人库命中时，个人候选仍能显示。
5. 正在输入五笔或拼音编码时不出现下一词候选，五笔首选顺序保持不变。
