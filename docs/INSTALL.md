# 万能五笔傻瓜安装指南

## 安装

1. 在 GitHub Release 的 `Assets` 区域下载 `WanNengWubi-v1.0.1.pkg`。
2. 双击下载的安装包。
3. 按系统安装向导点击“继续”和“安装”，输入 Mac 登录密码。
4. 安装完成后即可使用“万能五笔”。

安装包已经包含鼠须管 1.1.2、五笔 86 + 拼音混输配置、简体/繁体切换、通用联想数据库和个人学习模块，不需要提前准备其他文件。

## macOS 阻止打开时

当前安装包尚未使用 Apple Developer Installer 证书签名和公证。若系统提示无法验证开发者：

1. 打开“系统设置 → 隐私与安全性”。
2. 在安全提示旁点击“仍要打开”。
3. 再次确认，然后返回安装器继续。

## 升级与个人数据

安装器会把被替换的 Rime 配置备份到 `~/Library/Rime/backups/`。已有的 `personal_predict.userdb` 个人学习数据库会保留，不会写入安装包，也不会上传网络。

## 快捷键

- `Control + Shift + P`：开启或关闭联想。
- `Control + Shift + T`：切换简体和繁体输出。
