# 发布流程

1. 从 `main` 创建 `develop/vX.Y.Z` 版本分支；较大的独立功能再创建 `feat/<功能名>` 分支。
2. 修改配置或代码，并更新 `tests/cases.tsv`。
3. 执行 `make check`，在备用应用中完成真实输入测试。
4. 更新 `VERSION`、`upstream/versions.lock` 和 `CHANGELOG.md`。
5. 构建安装包；先保留上一版本安装包和 `~/Library/Rime` 备份。
6. 本机验证：安装、输入法数量、五笔优先、拼音补充、简体输出、候选横排、重启后仍可用。
7. 将版本分支合并回 `main`，提交并创建签名标签：`git tag -s vX.Y.Z`。仅自用时普通 annotated tag 也可以。
8. 在 GitHub Releases 创建版本介绍并按需上传经过验证的安装包。

建议版本路线：

- `0.1.0`：整理和稳定五笔 86 + 拼音混输基础功能。
- `0.2.0`：加入简繁切换并修复菜单栏图标。
- `0.3.0`：迭代可关闭的离线词汇联想和本地预测数据。
- `0.4.0`：加入完全离线的个人二元搭配学习。
- `0.5.0`：合并通用下一词数据库与个人学习，解决新用户冷启动。
- `1.0.0`：完成稳定安装、升级和回滚流程。
