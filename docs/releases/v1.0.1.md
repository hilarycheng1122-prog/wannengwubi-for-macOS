# 万能五笔 v1.0.1

这是面向普通用户的一体化安装版，输入功能与 v1.0.0 相同，重点改进安装体验。

## 最简单的安装方法

在下方 `Assets` 下载 `WanNengWubi-v1.0.1.pkg`，双击并按 macOS 安装向导操作。安装包内含鼠须管 1.1.2、万能五笔配置、通用联想数据库和个人学习模块，不需要使用终端。

当前安装包尚未使用 Apple Developer Installer 证书签名。若 macOS 阻止打开：

1. 先双击一次 `WanNengWubi-v1.0.1.pkg`，出现阻止提示后点击“好”或“完成”。
2. 打开“系统设置 → 隐私与安全性”。
3. 向下滚动到“安全性”，找到“已阻止打开 WanNengWubi…”提示。
4. 点击“仍要打开”，使用 Touch ID 或输入 Mac 登录密码。
5. 再点击一次“打开”，返回安装器继续。

如果没有看到“仍要打开”，请重新双击安装包触发一次提示，然后立即回到“隐私与安全性”查看。如果系统提示“将损坏你的电脑”或“检测到恶意软件”，请不要继续安装。

## 主要功能

- 五笔 86 与汉语拼音混合输入，五笔候选优先。
- 普通候选和联想候选默认统一为简体。
- 根据已经上屏的中文提供最多 7 项通用联想，并在本机学习个人常用搭配。
- 粘贴和应用外部文本变化不触发联想或个人学习。
- `Control + Shift + P` 开关联想。
- `Control + Shift + T` 切换简体和繁体输出。

## 升级与隐私

安装前会自动备份已有 Rime 配置，个人学习数据库会保留。安装包不包含任何用户的个人输入历史，全部功能离线运行。
