# 万能五笔 v1.0.0

首个正式版本，面向 macOS 鼠须管，完全离线运行。

## 主要功能

- 五笔 86 与汉语拼音混合输入，五笔候选优先。
- 横向候选栏和万能五笔品牌图标。
- 普通候选和联想候选默认统一为简体。
- `Control + Shift + T` 在简体和繁体输出之间切换。
- 根据已经上屏的中文提供通用下一词联想，最多显示 7 项。
- 在本机学习“上一词 → 下一词”的个人搭配，并将常用结果提前。
- 粘贴、菜单粘贴和应用外部文本变化不触发联想或个人学习。
- `Control + Shift + P` 开启或关闭联想。
- 个人数据完全保存在本机，可备份和清空，不上传网络。

## 安装

先安装鼠须管 1.1.2，然后在项目目录执行：

```bash
make prediction-alpha
make install-universal-learning
```

安装脚本会先备份现有 Rime 配置。安装完成后切换一次其他输入法，再切回万能五笔。

## 数据位置

- 通用预测数据库：`~/Library/Rime/predict.db`
- 个人学习数据库：`~/Library/Rime/personal_predict.userdb`

执行 `make reset-personal-learning` 可以先备份再清空个人学习数据。
